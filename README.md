# دراويز — قائمة مطعم تجريبية

واجهة عربية باتجاه RTL، متجاوبة للجوال والحاسوب، تعمل بـ HTML وCSS وJavaScript دون تبعيات خارجية أو خطوات بناء. جميع رسومات الأطباق SVG محلية. الأطباق والأسعار ومعلومات الحساسية بيانات توضيحية وليست قائمة مطعم حقيقية.

## التشغيل

يتطلب Node.js 20 أو أحدث. من مجلد المستودع:

```sh
npm start
```

الخادم يعمل على المنفذ `3000`، ويمكن تغييره بواسطة `PORT`. للتطوير مع إعادة تشغيل الخادم عند تغيير ملفاته: `npm run dev`. لا حاجة لتثبيت حزم أو إعداد أسرار أو قاعدة بيانات. يجب تقديم الواجهة عبر HTTP لدعم وحدات JavaScript.

## المزايا

- تصنيفات وبحث عربي يتجاهل التشكيل واختلافات الألف.
- تفاصيل الأطباق ومسببات الحساسية في نافذة تدعم لوحة المفاتيح والإغلاق بـ Escape.
- سلة محفوظة في `localStorage`، تعديل الكميات وإزالة الأطباق وإفراغ السلة.
- ملاحظات ونسخ ملخص الطلب؛ بديل نسخ يدوي عندما لا تتوفر صلاحية الحافظة.
- حالات البحث الفارغ والسلة الفارغة، دعم تقليل الحركة، وأسماء للأزرار لقارئات الشاشة.

السلة لا ترسل طلبًا أو دفعة، ولا تتصل بمطعم أو بوابة دفع. لا تُخزّن الملاحظات بعد تحديث الصفحة. إن منع المتصفح التخزين، تعمل السلة خلال الجلسة الحالية فقط. لا توجد لوحة إدارة أو حسابات أو خدمات خلفية للطلبات.

## تعديل القائمة

عدّل `menu-data.js` لتغيير الأطباق والأسعار والتصنيفات ومسببات الحساسية. كل طبق يحتاج معرّفًا فريدًا واسم رمز رسم في `images/food.svg`. الرسومات توضيحية وليست صورًا للأطباق. الهوية والألوان في `style.css`، والمحتوى الرئيسي في `index.html`.

## التحقق

```sh
npm test
```

تختبر مجموعة Node البحث العربي، سلامة الكميات المحفوظة، حساب المجموع، ملخص الطلب، وتقديم الأصول وحماية ملفات المستودع عبر HTTP. لا تتطلب تثبيت حزم. في بيئات التنفيذ التي تمنع المقابس، يجب تشغيل الخادم واختبارات HTTP عبر آلية الصلاحيات المدعومة.

اختبار واجهة اختياري عندما تتوفر Python Playwright وChromium:

```sh
# مع تشغيل npm start في عملية مستقلة
python3 tests/browser.py
```

يتحقق من البحث والتصنيفات والتفاصيل والسلة واستعادتها بعد التحديث والنسخ اليدوي والعرض على الجوال، ويكتب لقطات إلى `/tmp/draweez-desktop.png` و`/tmp/draweez-mobile.png`.
